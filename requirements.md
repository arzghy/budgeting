# Requirements - Website Budgeting

## Tujuan
buatkan saya sebuah website budgeting untuk pacar saya. pacar saya merasa pusing dalam membuat
rencana budgeting. oleh karena itu, saya ingin buat website budgeting yang lucu dan interaktif
untuk pacar saya. berikut permintaan fiturnya:

## Fitur
1. Color pallete warna ijo pastel dan pink pastel (#f6dbe2, #c2d772, #f6ffd3, #f6c5c1)
2. ada pengeluaran, save money (nabung), list kebutuhan status habis/tidak jadi kalau habis langsung masuk ke pengeluaran.
3. liat semua skin care sama make up (crud). beda skin care dan make up beda section. pengeluaran lainnya seperti jajan atau intinya pengeluaran selain 2 itu. nanti di pengeluaran lainnya ada pembagian juga
4. fitur nabung contoh wishlist. ada wishlist barang ini harganya segini nanti ada tombol purchase dan kalau udah purchase langsung masuk ke pengeluaran. terus ada fitur progress nabung yang di-input manual jadi sisa berapa lagi yang harus ditabung
5. di save money, ada section nabung untuk wish list dan nabung untuk jaga jaga.
6. saat buka web, menampilkan landing page terkait fiturnya kemudian untuk mengakses fiturnya, harus login terlebih dahulu
7. ada system auth login yang terintegrasi dengan OAuth Google
8. pakai tech stack next.js, mongodb, three.js
9. tambahkan library lenis smooth scrolling, lottiefiles karena mau buat webnya lucu
10. dia suka paus, jangan lupa tambahin unsur yang ada paus (tapi jangan pakai emoji)
